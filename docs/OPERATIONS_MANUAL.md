# Operations Manual

## System Overview
Anchor Fashion is a composable commerce platform built on Next.js and Supabase. The system leverages Edge runtimes, severless functions, and third-party SaaS integrations for email, payments, and analytics.

## Daily Operations

### Health Monitoring
- Continuously monitor `/api/health` via external uptime tools (e.g., BetterStack, Pingdom).
- Review the `obs_incidents` table in Supabase for any automated SEV-1 or SEV-2 alerts generated by the `ObservabilityService`.

### Error Monitoring
- Check the Sentry dashboard daily for unhandled client or server exceptions.
- Prioritize issues affecting the `checkout` or `payment` flows.

### Payment Monitoring
- Reconcile Stripe/SSLCommerz dashboards against the `payments` table.
- Webhook failures will be logged with a `retry_count`. Monitor `webhook_events` for records stuck in the `failed` state.

### Inventory & Shipping Monitoring
- Review `warehouse_stock` anomalies. Out-of-sync inventory usually stems from race conditions or failed webhook rollbacks.
- Check Courier API (FedEx, DHL) logs for shipping label generation failures.

### Analytics Monitoring
- Ensure GA4 and Meta Pixel data streams are receiving page views and purchase events.
- Check Google Search Console for any new indexing errors on product pages.
