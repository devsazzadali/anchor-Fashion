# Anchor Fashion Enterprise Design System

## Overview

This document serves as the foundation for our shared UI components. All components adhere to strict accessibility (WCAG AA) standards and support dark mode via CSS variables.

## Tokens

- Colors: Configured in app/globals.css and tailwind.config.ts
- Typography: Inter / system fonts
- Spacing: 4px base scale

## Usage

Import components from @/components/ui or other domain-specific folders like @/components/layout and @/components/data-display.
